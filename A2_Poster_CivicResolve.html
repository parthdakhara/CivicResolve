Problem Statement

Modern urban municipalities face severe inefficiencies in handling citizen grievances. Traditional phone and paper complaint desks suffer from:

Lack of Traceability: Complaints are misplaced with zero tracking tokens or audit logs.
Absence of Enforceable SLAs: No time-bound escalation exists for road craters, contaminated water, or live electric hazards.
Inter-Departmental Silos: Citizens cannot identify whether an issue falls under Sanitation, Water, Roads, or Electrical.
Need: A unified, responsive web portal providing instant lodging, automated departmental routing, live progress stepper, and citizen feedback.
2

Project Objectives

MVC Architecture: Construct a decoupled, scalable 3-tier ASP.NET Core 8 Web App.
Relational Persistence: Implement Code-First Entity Framework Core with MySQL and automatic schema seeding.
Robust Validation: Enforce strict server & client data annotations for email, phone, ward, and file size.
State Management: Utilize HttpContext.Session for citizen tickets & officer roles, plus TempData for flash alerts.
Accountability & Analytics: Provide SLA deadline timers, audit trails, and administrative analytical dashboards.

Conclusion

CivicResolve successfully demonstrates how modern ASP.NET Core MVC combined with Entity Framework Core and MySQL delivers an enterprise-ready, transparent municipal governance solution.
